## How Harmonia uses it

Google ADK defines the specialist team and strict handoffs. Muse Spark performs bounded specialist reasoning, Muse Voice Transcribe and Muse Image handle media, the worker runs the team in-process, and workspace memory supplies provenance-bearing advisory facts.
