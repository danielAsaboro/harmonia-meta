Every cognitive call in Harmonia goes to a Meta model. Role policy fixes the configured model, reasoning effort, output limit, eligible tasks, and timeout.

## How Harmonia uses it

| Work | Model |
|---|---|
| Coordinator, Ryan, Nimi, Temi, Noni, Dara, Maya, Nova | Muse Spark 1.3 on Meta Model API (Chat Completions) |
| Any role with `*_PROVIDER=baseten` | Muse Spark Open (`meta-models/muse-spark-open-1026`) on Baseten |
| Public research for Nimi and Ryan | Muse Spark with the built-in `web_search` tool (Responses API) |
| Audio and video transcription | Muse Voice Transcribe 1.0 (`/v1/asr/transcribe`) |
| Uploaded images (screenshots, slides, charts, photos) | Muse Spark image understanding (`/v1/responses`, strict JSON): verbatim visible text plus up to 12 observations, each a `frame` segment pointing at the stored image |
| Visual evidence from uploaded video | Muse Spark video understanding (`/v1/responses`, strict JSON) on a 2 fps, 480 px proxy; each observation becomes a `frame` segment backed by an ffmpeg still |
| Approved image generation | Muse Image 1.0 (`/v1/images/generations`) |
| Narrated video scene plan | Muse Spark (`/v1/responses`, strict JSON) with the `narrated-video-production` skill |
| Narrated video frames | Muse Image 1.0, one vertical 2:3 frame per scene |
| Voiceover and video narration | Meta MMS-TTS (`facebook/mms-tts-eng`, open weights, self-hosted on CPU) |
| Listen-back check on generated audio and video | Muse Voice Transcribe 1.0 |
| Subject tracking for vertical and square clips | SAM 3.1 (`/v1/responses`, boxes only) on a 5 fps, 640 px proxy |

Roles set `reasoning_effort` instead of temperature, and structured output uses strict `json_schema` response formats. Inputs are typed and bounded. Source-derived claims must keep their evidence references. The application reserves budget before each call, records normalized usage, and validates output before advancing a stage.

Meta Model API has no speech synthesis or video generation endpoint, so Harmonia composes both from Meta parts: Muse Spark plans the scenes, Muse Image draws them, Meta's open-weight MMS-TTS speaks them, ffmpeg cuts the MP4, and Muse Voice Transcribe listens back. A render whose transcript matches less than 60% of the approved narration fails instead of shipping. Harmonia does not generate music.

## Security and authority

Models cannot approve strategies or effects, mutate Firestore, schedule externally, publish, or create verification receipts. Multimodal input is attached only from an authorized source package. The API key is read from the environment on every call and never stored on an agent. Video proxies over 45 MB go through the Files API as one-hour uploads that are deleted as soon as the call returns. Every direct call retries 429, 500, and 503 responses, honoring `Retry-After`, as Meta's error-handling guide recommends.

## Failure behavior

Unavailable configured models fail visibly. Output that violates a schema, evidence boundary, or role boundary is rejected as a protocol failure.

## Evidence status

Model routing and output contracts are locally tested. Authenticated Meta Model API calls and their billed usage require captured provider and Cloud Trace evidence.
